## Security boundaries and residual risks

Raster geometry, depth, copies, quality, media and shifts are bounded before encoding. Link-time stripping removes unused vendor CLI/color/decoder paths from the installed filter. Two deprecated `sprintf` warnings remain in unchanged unused vendor color code; the full upstream library is not declared vulnerability-free.

USB responses have deadlines and bounded HTTP/XML parsing. Runtime has no internet client, telemetry, shell or firmware updater. Local USB access does not authenticate a hostile device. Selected PDFs reach Apple's PDFKit: limits do not cap all framework allocations/time, and Utility is not App Sandbox isolated. Cropping does not securely redact secrets.

Installer needs administrator authorization. Fixed paths, symlink and queue/app identity checks do not defeat an already privileged attacker. Mock tests are not a real upgrade/removal on an expendable Mac.

EOF detection relies on observed CUPS read-request/buffering behavior. Current implementation, fragmented input and legacy/v2 headers are covered; future CUPS versions must rerun regressions. Failed jobs omit a success end marker; physical recovery/cancellation remain untested. Existing custom-size protocol paper code zero was retained because no evidence justified guessing another hardware code.
