HP LaserJet P1102 Native

Native ARM64 USB printing for Apple Silicon Macs (M1 or newer). No Rosetta or original HP driver is required.

Connect the powered-on P1102 before installation. The installer adds the HP LaserJet P1102 Native queue, preserving the existing HP queue and your default selection. If disconnected, add the printer later using HP LaserJet P1102 Native ARM64, 1.6 in Printers & Scanners.

Monochrome, single-sided printing on A4, A5, A6, Letter and Legal. No downloads, background service, firmware changes or changes to macOS security settings.

This is an independent, vibe-coded community project with AI assistance, under GPL v2 or later. It is not an HP or Apple product. The package is not Developer ID signed or notarized. Physically tested on one P1102 with macOS 27.0.1; future macOS compatibility is not guaranteed.

HP LaserJet P1102 Native

Nativní tiskový ovladač pro Macy s procesorem Apple Silicon (M1 a novější). Nepotřebuje Rosettu ani původní ovladač HP.

Před instalací připojte zapnutou P1102 přes USB. Instalátor přidá tiskárnu „HP LaserJet P1102 Native“. Původní tiskárnu ani výchozí volbu nezmění.

Pokud tiskárna není připojená, po instalaci ji přidejte v Nastavení systému, Tiskárny a skenery. V nabídce Použít zvolte Vybrat software a vyberte „HP LaserJet P1102 Native ARM64, 1.6“.

Podporuje černobílý jednostranný tisk, A4, A5, A6, Letter a Legal. Automatický oboustranný tisk tento model nemá.

Instalátor uloží filtr a licenci do /Library/Printers/P1102Native a popis tiskárny do /Library/Printers/PPDs. Nic nestahuje, neinstaluje službu na pozadí a nemění zabezpečení macOS.

Otevřený kód pod GPL v2 nebo novější, s převodníkem foo2zjs a kompresí JBIG-KIT. Jde o nezávislý ovladač, nikoli produkt HP. macOS 28 zatím nebyl testován.
