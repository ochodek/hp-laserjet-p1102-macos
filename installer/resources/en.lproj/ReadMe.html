Before installing

Compatibility

Requires an Apple Silicon Mac (M1 or newer) and the USB P1102. Validated on macOS 27.0.1. The build supports macOS 11 or newer, but other macOS releases and printer models have not been physically validated.

What changes

Installs P1102 Utility in Applications and native printing components under /Library/Printers. Adds or updates the HP LaserJet P1102 Native queue. Your default printer and original HP queue are preserved. A conflicting queue is not replaced; multiple connected P1102s require manual selection.

No downloads, firmware changes, background agent, telemetry or change to macOS security settings.

Licence and trust

GPL version 2 or later. The next screen shows the original licence. Full notices and matching source are included with the driver. No extra EULA or restrictions are added. This package has no Developer ID signature or notarization; do not disable Gatekeeper or SIP.

Removal and support

The installed Uninstall.command removes this project's queue and files after confirmation and administrator authorization. Documentation and support: project on GitHub.
